# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for a security problem. A public issue tells attackers about the problem before it is fixed.

Report it privately instead:
- on GitHub, open the **Security** tab of this repository and choose **Report a vulnerability**; or
- contact us privately at **[YOUR PRIVATE CONTACT]** (replace this before you publish: for example a security email address, or a direct-message handle you watch).

Please include what you found, how to reproduce it, and what an attacker could do with it. Never include real keys or other people's data in a report.

We aim to answer within 7 days and to tell you when the problem is fixed. We will credit you in the release notes unless you ask us not to.

## Supported versions

Only the latest release receives security fixes.

## If you find a leaked key

If you find a key, token or password in this repository or its history, report it privately as above. We will revoke it first, then remove it.
