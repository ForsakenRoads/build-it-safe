# Part I. How it goes wrong {#part-1 .part}

::: {.part-intro}
These are eight true stories from 2024 to 2026. In each one, someone built or ran software with AI tools, or used a tool that AI made more powerful, and something went wrong. Some of the people involved were beginners. Some were large companies with full security teams.

Each story is short. It says what happened, why it happened in plain words, and what you can do so it does not happen to you. Every fact has a numbered note that points to the Sources appendix, so you can read the original report yourself.

None of these stories is here to scare you. They are here because each one teaches a lesson that experienced engineers learned the hard way, and you can learn it in five minutes instead.
:::
