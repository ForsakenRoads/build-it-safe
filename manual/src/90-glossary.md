# Glossary {#glossary .matter .unnumbered}

::: {.glossary}
API key
:   A password that lets a program use a paid service. Whoever holds it can spend your money or read your data.

Authentication
:   Proving who you are, for example by signing in.

Authorization
:   Deciding what a signed-in person may see or change.

Backup
:   A copy that is somewhere else, that cannot be deleted in a hurry, and that you have restored from.

Bucket
:   A named storage container in a cloud storage service such as Backblaze B2.

Capability
:   One action that a key is allowed to perform, such as "write files" or "delete files".

Certificate
:   A file that proves a website is really the site it claims to be. HTTPS needs one.

Clickjacking
:   A trick in which a fake site shows your page inside its own, invisibly, so visitors click your buttons without knowing.

Content Security Policy (CSP)
:   A header that tells the browser where a page's scripts, styles and images may come from.

CVE
:   A public ID number for a known security flaw, such as CVE-2025-55182.

Dependency (package)
:   Code written by someone else that your project downloads and uses.

Deployment
:   One published version of a website or app.

Deny rule
:   A setting that tells an AI agent's software never to allow a certain action.

Development
:   A copy of your app and data where you build and test. Breaking it should cost nothing.

Diff
:   The list of changes between two versions of a project.

Environment variable
:   A named setting, such as `OPENAI_API_KEY`, that your app reads when it starts, so the value stays out of your code.

Framework
:   The large body of ready-made code an app is built on, such as Next.js, React or SvelteKit.

Git, GitHub
:   Git saves versions of a project. GitHub is a website that stores git projects.

Hard cap
:   A spending limit that stops the service when it is reached. Compare with an alert, which only notifies you.

Header
:   An instruction a server sends along with a page, which the browser obeys.

Hook
:   A small program that an AI agent's software runs before an action, and that can refuse the action.

HTTPS
:   An encrypted connection between a browser and a website, shown by the padlock in the address bar.

HSTS (Strict-Transport-Security)
:   A header that tells the browser to use only HTTPS for a site.

Install script
:   A small program inside a package that runs automatically when you install it.

Least privilege
:   Giving every key, account and tool the smallest power that still does its job.

Lifecycle rule
:   A storage setting that decides when old or hidden versions of files are deleted.

Lockfile
:   A file that records the exact version of every package a project uses.

Loopback
:   The address `127.0.0.1`, which means "only this computer".

Malware
:   Software written to harm you, such as a program that steals passwords.

MCP server
:   A plug-in that gives an AI agent new tools, such as access to GitHub, a database or email.

Mesh VPN
:   A private network that connects your own devices to each other, wherever they are.

Mirror
:   A copy kept identical to the original. Deleting a file deletes it from the mirror too, so a mirror is not a backup.

Multi-factor authentication (MFA)
:   Signing in with a password plus a second proof, such as a code or a passkey.

Object Lock
:   A storage setting that prevents files from being changed or deleted until a set date.

Passkey
:   A sign-in method that uses a secret stored on your device instead of a password. It works only on the real website.

Patch
:   An update that fixes a flaw.

Phishing
:   A fake website or message that tricks you into giving away a password or code.

Port
:   A numbered door on a computer through which a program listens for connections.

Production
:   The live system your users use, with their real data.

Prompt injection
:   Hiding instructions inside text that an AI will read, so it obeys the attacker instead of you.

Public prefix
:   A variable name prefix, such as `NEXT_PUBLIC_`, that copies the value into the code every visitor downloads.

Remote code execution
:   A flaw that lets someone far away run commands on your machine.

Revoke
:   To cancel a key at the service that issued it, so it no longer works anywhere.

Rotate
:   To replace a key with a new one and then revoke the old one.

Row-level security (RLS)
:   Rules inside a database that decide which rows each user may read or change.

Sandbox
:   A fence, enforced by the operating system, that limits what a program can reach.

Secret
:   Anything that grants access: keys, passwords, tokens, connection strings.

Secret scanner
:   A tool that reads your changes and stops you when it sees something that looks like a key.

Skill
:   A packaged set of instructions and files that teaches an AI agent a task.

Slopsquatting
:   Registering a package name that AI models invent, so people who follow the AI's advice install malware.

SSH, SSH tunnel
:   SSH is the standard tool for logging in to another computer securely. An SSH tunnel carries one connection through that encrypted link.

Supply chain attack
:   An attack on something you trust and download, instead of on you directly.

Token
:   A standing key that lets an app or tool act on your account until you take it back.

VPN
:   An encrypted tunnel from your device to a server run by a VPN company, which then carries your traffic onward.

Webhook
:   A web address on your server that another service calls to report an event, such as a payment.
:::
